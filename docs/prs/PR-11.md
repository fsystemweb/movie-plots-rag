- **Cost per 1,000 questions stays "pending credentials"** as hand-written text next to the speed block: it needs tokens per question from a real run and the provider's price list, which are not in the repo. CREDENTIALS.md says how to compute it.
- **Build totals are "as of change 10" and untested by design**: asserting them against `docs/TOKEN_USAGE.md` would break the test on `main` as soon as PR-11's own row lands.

- **Sentence-length heuristic** (module docstring of the test): limit 24 words per sentence, code fences/comments/tables/headings skipped, bullets as separate sentences, all other lines of a paragraph joined and split on `.`, `!`, `?` + space.
- **Config, not constants**: `eval.overview_path` in `config.yaml` (like `eval.readme_path`); the CLI test fixture points it at a temp file so no test rewrites the real overview.
