## Decisions
- **No Kaggle SDK.** `kaggle` imports and authenticates at import time and drags in heavy dependencies; the download is one
  Basic-auth GET (`/api/v1/datasets/download/<slug>`) with size limits and a zip-slip-safe extraction. Everything is
  configurable in `config.yaml` (`data.*`).
- **No no-auth mirror.** A search found no mirror of this exact dataset with a verified licence; catalogues disagree
  (CC BY-SA vs CC BY-NC-SA). Documented in `docs/DATASET.md`. The fixture is synthetic, marked as such in
  `tests/fixtures/README.md`, and its `Wiki Page` URLs end in `_(synthetic_film)` so they cannot be mistaken for citations.
- **`movie_id` row index** is the 0-based position in the raw file, counted before dropping rows, so ids survive changes to
  cleaning thresholds.
- `director`/`cast` `Unknown` also become null (the spec only names genre/origin) so that chunk headers never read "Unknown".
- `retrieval.prefetch_limit` changed from the PR-01 placeholder 40 to 50 to match KICKOFF section 1 ("top 50 each").
- Config precedence: init kwargs, environment, `.env`, `config.yaml`; nested overrides with `__` (`LLM__CHAT_MODEL`); the
  well-known `QDRANT_URL`, `NEBIUS_BASE_URL`, `MCP_URL`, `LANGSMITH_PROJECT` are applied on top. `config_hash()` hashes the
  effective tunables only (no secrets, no switches).
- `observability.configure_tracing()` forces `LANGSMITH_TRACING=false` when no key exists and clears the langsmith client's
  memoised env reads, so `@traceable` stays a silent no-op.
- `pyproject.toml`: runtime deps (`pydantic`, `pydantic-settings`, `pyyaml`, `langsmith`, `httpx`) and a narrow ruff
  `E501` ignore for the fixture generator (long vocabulary lists under `# fmt: off`). `tests/unit/test_package.py` no longer
  expects `download` to be a stub.
- `python -m movie_rag.doctor` / `movie_rag.ingest.download` entry points are covered via `runpy` (`alter_sys=True`).
