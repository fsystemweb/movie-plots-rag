## Decisions
- No runtime dependencies yet; each later PR adds its own (CI uses `--all-extras --dev`, an empty extras table is valid).
- Coverage gate stays on the command line (`COV_FAIL_UNDER := 80` in the Makefile), never in `pyproject.toml`.
- Healthcheck uses bash `/dev/tcp` against `/readyz` because the Qdrant image has no curl/wget.
- `make up` uses `docker compose up -d --wait qdrant` so it returns once healthy.
- Markdown under `.claude/` is excluded from `ruff format` (skills contain illustrative snippets and are protected).
- pre-commit revs match the locked ruff (0.16.10) to avoid format drift between hook and CI.
- `make ci` marker name is `ci-<NN>.ok` from branch `pr/NN-...`, falling back to the sanitized branch name.
