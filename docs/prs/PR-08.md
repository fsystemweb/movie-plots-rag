## Decisions
- **Data location**: `src/movie_rag/eval/data/questions_v1.jsonl` (package data, travels with the wheel). The repository's `.gitignore` had `data/` (the downloaded dataset), which also matched this folder; added a negation for it and an ignore for `*_generated.jsonl`.
- **Gold for filtered questions** is one film that satisfies the filters; the semantic part of the question must pick it out (three filters isolate it alone, the others leave 2 to 6 films).
- **Unanswerable gets an `absent_title` field** (required there, forbidden elsewhere) so "their films are absent from the fixture" is checkable. Two unanswerable questions carry filters that match no film.
- **No cast questions**: cast is payload only, not in the chunk text (`Title (Year) | Genre | Director`), so the system could not answer them.
- **Each film is gold at most once** across the set (checked), so one lucky retrieval cannot score twice.
- **Anchor director "Boris Zaitsev"** (backlog PR-02 QA n3) is never named in a question; no rename was attempted because the fixture is protected by a byte-identical generator test and the change is not needed here.
- **The generator only writes fuzzy questions** and never writes over the committed file (`eval.generated_path`).
- **Upload never updates**: an existing dataset is skipped; bump `eval.dataset_name` for a new version.
- Informal sanity check (scratch script, not committed, not a result): real FastEmbed models on the in-memory fixture index put the gold film at rank 1 for BM25 on all ten fuzzy questions and in the top 8 for 9 of 10 with dense. This is why the limitations section of `docs/EVAL_SET.md` warns that the fixture separates modes little.
