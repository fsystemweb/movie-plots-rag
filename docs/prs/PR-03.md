## Decisions
- **Token definition.** A token is a WordPiece token of the dense model's own tokenizer, excluding `[CLS]`/`[SEP]` (`FastEmbedder.count_tokens`), so the budget is in the units the embedding model sees. The chunker takes any `Callable[[str], int]`; unit tests use one-word-one-token (exact budgets), the integration test checks the real counter (`Hello, world!` is 4; every real chunk is at most 250 tokens). The budget applies to plot text; the header adds about 15 tokens, far below bge's 512 limit. The model's tokenizer truncates at 512, so counts saturate there (only an over-long single sentence is affected, and those are split on words anyway).
- **Overlap** is whole trailing sentences of the previous chunk totalling at most 40 tokens (possibly none), and each chunk always adds at least one new sentence, so chunking terminates.
- **Sentence splitting** is a small regex (split before an uppercase letter, digit or quote; abbreviation and initialism guards) rather than an NLP dependency; limitation recorded in the backlog.
- **Full plot on chunk 0 only** (`full_plot`). `get_movie` does one `retrieve` of `point_id(movie_id, 0)` (public helper in `ingest/index.py`): no scroll, no filter. Storing it on every chunk multiplies payload size by the chunk count; a second collection adds something else to create and keep in sync. The chunk text is stored without the header (clean snippets); the header is rebuilt from the payload metadata.
- **Payload** also keeps `n_chunks`, and `wiki_page` carries the cleaned `wiki_url`; unknown genre/origin/director/cast are stored as null.
- **Resume by id before embedding** (`retrieve` without payload/vectors) so a resumed run skips the expensive part; the price is that a changed chunk keeps its old content until `RECREATE=1` (backlog).
- **Mismatch guard.** `ingest_csv` reads the count back from Qdrant and raises `IndexingError` if it is lower than the chunks produced; an existing collection with a different dense size raises with the `--recreate` hint.
- **Query-side embedding** (`embed_dense_query`/`embed_sparse_query`) lives on the same `Embedder` protocol now so PR-04 reuses it; `query_embed` is used for queries, `embed` for documents, for both models.
- **Tracing.** `ingest_csv` is `@traceable(name="ingest")` with `process_inputs` limited to csv path, collection and recreate (never the settings, client or embedder). Metadata via `run_metadata()` plus `source`/`collection`; `retrieval_mode` is overridden to `n/a`.
- **Integration tests without a service.** Skips are forbidden outside live tests, and `make check` must pass without Docker, so the module uses `QDRANT_URL` when set (CI) and `QdrantClient(":memory:")` otherwise; payload-index assertions only run against the service. The URL is read at import because the autouse fixture scrubs the variable per test.
- `logging.getLogger("httpx")` is set to WARNING in the CLI so the report is not buried in one line per request.
