## Summary
- New `src/movie_rag/agent/` package: `MovieAgent.ask(question, mode=None)` runs a LangChain `create_agent` tool-calling loop over the four PR-05 MCP tools (`MultiServerMCPClient`, streamable HTTP at `mcp.url`) with `ChatOpenAI(base_url=llm.base_url, model=llm.chat_model, temperature=0)` on Nebius; model and tools load lazily at call time.
- Hard cap of `llm.max_tool_calls` (4) tool calls per question via `ToolCallLimitMiddleware`; calls over the cap are refused (the model sees an error) and counted. A model that never stops is cut off at the step limit and the run becomes an abstention.
- Versioned prompt `agent/prompts/system_v1.md` with the answer rules. Citations are built from the films the tools returned; the model's text only selects which retrieved films are mentioned (exact `Title (Year)` or `movie_id`), so an invented film is dropped. No cited film means `abstained=True` and a standard abstention text.
- Typed `Answer` (text, citations, retrieved films, tool calls, usage, latency, run metadata incl. git sha / prompt version / chat model / embedding model / retrieval mode / config hash). The run is a LangSmith span carrying the same metadata; secrets typed into a question are scrubbed before the model or any trace sees them.
- `make ask Q="..."` (`MODE=`, `JSON=1`): without `NEBIUS_API_KEY` it prints `set NEBIUS_API_KEY — see docs/CREDENTIALS.md` and exits 2; MCP server down gives an actionable message and exit 1.

## Decisions
- Citation selection: the text picks among retrieved films by exact `Title (Year)` (when unambiguous) or `movie_id` token; the cited title/year/link always come from the tool result. Alternative (structured-output `response_format` with `movie_ids`) was rejected: its extra tool call would compete with the 4-call cap and depends on Qwen's tool-calling quality.
- No cited film means the answer text is replaced with a fixed abstention message (an answer that names films nobody retrieved must not reach the user). The model's own text is not kept in the object.
- `ToolCallLimitMiddleware(exit_behavior="continue")` over `"end"`: the model gets to answer after the refusal instead of ending on a canned "limit exceeded" message; `recursion_limit = 4 * (cap + 2)` bounds a model that ignores refusals.
- `mode` option (`--mode`, `MODE=`) pins the retrieval mode with an MCP tool interceptor (PR-07 sidebar and PR-09 per-mode experiments will need it); default is the model's choice.
- Exit codes: 2 = missing credentials / usage error, 1 = other expected failures (MCP down, bad config), 0 otherwise (abstention is a success).
- `agent.prompt_version` now validated as `^[a-z0-9_]+$` (no path traversal); `agent.max_citations` and `agent.mcp_timeout_s` added to `config.yaml` (config hash changes, nothing pins it).
- Test helper `Index` moved from `tests/unit/test_mcp_server.py` to `tests/index_fixture.py` to share it with the integration test; no behaviour change.
- `docs/token_usage.jsonl` is modified in the working tree by the token-tracking hook; it is protected and not part of this PR.
